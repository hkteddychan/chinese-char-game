# 📖 中文認字小遊戲

小朋友學中文認字嘅互動網頁遊戲 — 用讀音（聽）、字形（睇）、字詞配對三種方式，邊玩邊學。

## 🎮 三種玩法
- 🔊 **聽字揀字** — 錯讀音，揀出佢講嗰個字
- 👀 **睇字揀音** — 睇住個字，揀啱讀音（普通話拼音 + 注音 + 粵拼提示）
- 📝 **字配詞語** — 詞語缺咗個字，揀返啱嘅字

## 📚 字庫分級（一共 237 字）
- **一年級**：最常用基礎字（數字、身體、自然）
- **二年級**：家庭、飲食、動作
- **三年級**：顏色、季節、學習用品
- **全部**：加埋高年級進階字

## 🔤 文字資料
每個字都有：
- 普通話拼音（含聲調）
- 注音符號
- 粵語拼音（jyutping）
- 常用詞語示例

## 🎙 發音
用瀏覽器內置 Web Speech API（TTS）朗讀，支援廣東話（zh-HK）優先，自動 fallback 普通話。

## 🛠 用法
純靜態網頁，無後端，直接開 `index.html` 就玩得。字庫喺 `wordbank/words.js`，方便加字。
